# واژه‌نگار

واژه‌نگار یک مترجم محلی و فرهنگ سه‌زبانهٔ فارسی، انگلیسی و آلمانی است. هر بند را کنار متن اصلی بخوانید، اصلاح کنید و نسخهٔ ویرایش‌شده را دریافت کنید. زبان منوها مستقل از جهت ترجمه انتخاب می‌شود.

| مشخصات | نام |
| --- | --- |
| دانشجو و توسعه‌دهنده | آنیتا بخشی |
| استاد | داریوش تصدیقی |
| دوره | LLMOps |

## اجرا در ویندوز

پس از نصب Python 3.12 و اجرای Ollama، در پوشهٔ پروژه PowerShell را باز کنید. دریافت مدل فقط بار اول لازم است.

```powershell
ollama pull qwen3:8b
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

نشانی محلی نمایش‌داده‌شده در ترمینال را باز کنید. تنظیمات اختیاری مدل و اجرای WSL در [راهنمای انگلیسی](README.md) آمده است.

## میز ترجمه

جهت و حالت ترجمه را انتخاب کنید. متن چندخطی را وارد کنید و بندها را با یک خط خالی جدا کنید. برای یک واژه، حالت خودکار مدخل فرهنگ می‌سازد. برای اصطلاح چندواژه‌ای می‌توانید حالت واژه‌نامه را دستی انتخاب کنید. معادل‌های اختصاصی را به شکل `inference = استنتاج` وارد کنید.

پس از ترجمه، می‌توانید هر بند را جداگانه ویرایش یا بازتولید کنید. هشدارهای عدد، درصد و شناسه برای بازبینی‌اند. پیش از بستن نشست، متن نهایی را دانلود کنید.

## آزمایشگاه پرامپت

۴۶ نمونه در شش جهت ترجمه موجود است. یک نمونه یا کل مجموعه را اجرا کنید، پاسخ‌های A و B را بخوانید و به وفاداری معنایی و روانی از ۱ تا ۵ امتیاز بدهید. بعد از ثبت نهایی، نسخهٔ پرامپت‌ها آشکار می‌شود. گزارش تفکیکی و فایل CSV برای ارائهٔ کلاسی در دسترس‌اند.

## منابع آموزشی

ماژول‌های آموزشی استاد داریوش تصدیقی در ساخت پروژه استفاده شده‌اند. جزئیات انتساب و مجوز فونت‌های همراه در [راهنمای اصلی](README.md#acknowledgments) آمده است.

## شنیدن و دریافت صوت
زبان مبدأ و مقصد را انتخاب کنید. تشخیص زبان پیشنهادی است و برای واژه‌های مبهم مثل Gift می‌توانید زبان را دستی انتخاب کنید. پس از فعال کردن صوت آنلاین، با زدن «شنیدن» فقط متن انتخابی به Microsoft Edge TTS فرستاده می‌شود. صدا برای هر بند و کل متن قابل پخش و دانلود در قالب MP3 است. نسخهٔ ویرایش‌شده هنگام درخواست مجدد با صدای زبان مقصد خوانده می‌شود. زمان ساخت صدا کنار پخش‌کننده نمایش داده می‌شود.

## تمرین شنیداری و نگهداری سند
صوت آنلاین را فعال کنید و در بخش تمرین شنیداری، ترتیب خواندن را انتخاب کنید. بعد از آماده‌سازی صدا، پخش، مکث، تکرار بند و انتخاب سرعت در دسترس است. بعد از ویرایش دکمهٔ ذخیرهٔ سند را بزنید. از بخش اسناد محلی می‌توانید متن، ترجمهٔ اولیه، ویرایش، آخرین بند و واژه‌نامه را بازیابی کنید. اسناد در SQLite روی دستگاه اجراکنندهٔ Streamlit نگهداری می‌شوند. این قابلیت برای استفادهٔ محلی تک‌کاربره است.
